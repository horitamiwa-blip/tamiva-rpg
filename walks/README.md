# さんぽメモ フォルダ

ここに Obsidian の散歩メモを `.md` ファイルとして置くと、
GitHub Actions がボーダ（Claude）・こぬこぬ（ChatGPT）・ぐろっくん（Grok）の
コメントを自動生成して `walks.html` に反映されます。

## ファイル形式

`walks/` 直下に1メモ1ファイルで置いてください（サブフォルダは無視されます）。

```markdown
---
title: となりの犬とすれちがった
date: 2026-07-31
---
今日は多神和と犬で近所を一周した。
きんもくせいの匂いがした気がしたけど季節はずれだった。
```

- `title` / `date` は frontmatter に書いてください（`date` は `YYYY-MM-DD`）。
- 本文はプレーンテキスト〜簡単な `**強調**` 程度で書けば表示されます。
- ファイル名は自由ですが、日付を先頭につけると並び替えしやすいです
  （例: `2026-07-31-inu-to-sanpo.md`）。

## 自動生成されるもの（手動で編集しないでください）

- `walks/manifest.json` — メモ一覧。push のたびに再生成されます。
- `walks/comments/<ファイル名>.json` — 3人のコメント。push のたびに再生成されます。

## セットアップ

APIキーの登録・GitHub Pagesの有効化・Obsidianとの同期方法は
リポジトリ直下の `WALKS_SETUP.md` を参照してください。
